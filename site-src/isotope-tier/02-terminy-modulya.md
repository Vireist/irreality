# Термины модуля

| Термин                   | Что означает                                                  |
|--------------------------|---------------------------------------------------------------|
| **АК**                   | Код пластины «Саркофаг», аблятивный композит                  |
| **Ядерный патрон**       | ВФ, ТБ, КИ, ПЛ. Против них работают абляция и жертвенный слой |
| **Абляция**              | Снижение Усугублённого урона, прошедшего «Саркофаг» (§1)      |
| **Жертвенный слой**      | Дополнительная потеря Целостности за ядерное попадание (§1)   |
| **Выжигание**            | Особый износ от плазмы, заменяет обычный (§3)                 |
| **Шоковая волна**        | Урон, который проходит сквозь броню всегда и целиком (§3)     |
| **Целостность импланта** | Запас прочности кибернетики. Обнуляется ЭМИ (§4)              |
