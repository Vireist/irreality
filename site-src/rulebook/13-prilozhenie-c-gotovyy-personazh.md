# Приложение C. Готовый персонаж

**Марта «Шов» Ковалёва.** Бывший военный хирург. Её отряд погиб, она вышла. Теперь работает в частной клинике и подпольно штопает тех, кому нельзя в больницу. Стреляет редко и неохотно, режет уверенно.

### Атрибуты

| Физические   |   | Социальные |   | Ментальные |   |
|--------------|---|------------|---|------------|---|
| Сила         | 2 | Влияние    | 1 | Восприятие | 3 |
| Ловкость     | 3 | Эмпатия    | 2 | Смекалка   | 3 |
| Выносливость | 2 | Сила воли  | 3 | Эрудиция   | 3 |

### Навыки

Неназванные навыки равны 0.

| Физические |   | Социальные       |   | Ментальные         |   |
|------------|---|------------------|---|--------------------|---|
| Атлетика   | 1 | Запугивание      | 1 | Медицина           | 5 |
| Реакция    | 2 | Убеждение        | 2 | Наблюдательность   | 3 |
| Скрытность | 1 | Обман            | 2 | Анализ             | 2 |
|            |   | Проницательность | 2 | Технические науки  | 1 |
|            |   |                  |   | Гуманитарные науки | 1 |

### Черты

- **Специализации:** Медицина «полевая хирургия» (бесплатная), Технические науки «токсикология» (6 очков).
- **Преимущество:** Железные нервы 2 (6 очков). +2 кубика к сопротивлению ужасу.
- **Недостаток:** Вина выжившей 2 (+6 очков). Отряд погиб, она вышла. Разговоры о том вечере, чужие похороны и слово «повезло» бьют каждый раз.

### Треки и пулы

**Здоровье 5** (Выносливость 2 + 3). **Рассудок 8** (Сила воли 3 + 5).

| Задача                                                 | Пул |
|--------------------------------------------------------|-----|
| Полевая хирургия (Ловкость + Медицина + специализация) | 10  |
| Диагноз, причина смерти (Восприятие + Медицина)        | 8   |
| Осмотреться (Восприятие + Наблюдательность)            | 6   |
| Выстрел (Ловкость + Меткость 0)                        | 3   |
| Защита (Ловкость + Атлетика)                           | 4   |
| Сопротивление ужасу (Сила воли ×2 + Железные нервы)    | 8   |
| Проверка на грани (Выносливость ×2)                    | 4   |

### Больные места

Погибший отряд. Дети под огнём. Клятва не бросать раненых.

Последнее работает в обе стороны: бросить раненого значит потерять Рассудок с надбавкой, а спасти раненого ценой риска даёт катарсис (§3.8).

### Снаряжение

Пистолет Glock 17 (+2, 17 патронов), ударный жилет КВ 2/6, хирургический набор, аптечка, старый седан.

### Проверка расчёта

Атрибуты: категории 4/3/6, база 1 каждому. Навыки: категории 4/7/11, база 0, Медицина при распределении 4. Свободные очки: 21 + 6 за недостаток = 27. Потрачено: Железные нервы 2 (2+4 = 6), Медицина 4→5 (5×3 = 15), специализация (6). Итого 27.

### Как играть

Шов не боец. Её место за укрытием с аптечкой, а не в конусе. Она вытаскивает тех, кто полез, и платит за это ночами. Вина выжившей будет всплывать каждую сессию: это оплаченный недостаток, а не декорация. Клятва даёт ей и самый опасный триггер, и единственный надёжный способ вернуть Рассудок.
