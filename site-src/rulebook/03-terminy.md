# Термины

| Термин            | Что означает                                                                       |
|-------------------|------------------------------------------------------------------------------------|
| **Пул**           | Сколько d10 вы кидаете. Обычно атрибут + навык ± модификаторы                      |
| **Успех**         | Кубик 6 и выше. Десятки считаются парами (§2.2)                                    |
| **Сложность**     | Сколько успехов нужно для проверки. Называет мастер (§2.3)                         |
| **Защита**        | Кубики, которые цель тратит против атаки (§4.3)                                    |
| **Разница**       | Ваши успехи минус успехи противника. Ноль или меньше означает промах (§2.4)        |
| **Рейтинг**       | Урон оружия. Пишется с плюсом: +2, +3, +4                                          |
| **Поглощение**    | Сколько пунктов урона пластина гасит за одну атаку (§6.1)                          |
| **Целостность**   | Запас прочности пластины. Тратится от поглощённого урона (§6.2)                    |
| **Обстрел**       | Одна атака огнестрелом по одной цели. Один расчёт урона, одно списание Целостности |
| **Трек**          | Шкала клеток, куда отмечается урон. Здоровье и Рассудок                            |
| **УС**            | Усугублённый урон. Опасные для жизни ранения (§3.1)                                |
| **ПОВ**           | Поверхностный урон. Ушибы, ссадины, истощение (§3.1)                               |
| **Травма**        | Недостаток, заработанный на грани смерти (§3.4)                                    |
| **Больное место** | То, что ранит персонажа сильнее обычного (§1.3, §3.5)                              |
